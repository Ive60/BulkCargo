Full description (EN)
BulkCargo is a practical tool for seafarers, deck officers and shipping agents working with bulk cargo. All calculations run on your phone, offline.
Features:
• Stowage factor (SF) converter
• Cargo weight and volume calculation
• Hold capacity
• Grain vs bale capacity comparison
• Multi-cargo calculation
• Trim and heeling
• Reference table of stowage factors for 50+ bulk commodities
Note: this app is an aid only. Results do not replace the ship's approved loading computer, stability booklet or the Master's judgement.
